## 🌟 Overview

Welcome to my professional portfolio! This project is a modern, responsive, and highly interactive showcase of my journey as a Software Engineer. Built with a focus on **User Experience (UX)** and **Performance**, it features a sleek dark theme, smooth animations, and a multi-page architecture.

## ✨ Key Features

- **🎯 Interactive Hero Section**: Dynamic typewriter effects highlighting my core skills and professional summary.
- **📱 Multi-Page Navigation**: Dedicated routes for Home, About, Skills, Projects, and Experience using `react-router-dom`.
- **🛠️ Technical Arsenal**: Categorized display of my tech stack (MERN, Python, AI/ML, Databases).
- **🚀 Project Showcase**: Detailed project cards with live demo links and GitHub repository access.
- **📜 Certifications & Achievements**: A comprehensive timeline of my educational background and professional certifications.
- **✨ Smooth Animations**: Powered by `framer-motion` for a premium, high-tech feel.
- **🎨 Glassmorphism UI**: Modern design language using Tailwind CSS and backdrop-blur effects.

## 🛠️ Built With

- **Frontend Framework**: [React.js](https://reactjs.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Routing**: [React Router](https://reactrouter.com/)
- **Interactivity**: [Typewriter Effect](https://www.npmjs.com/package/typewriter-effect)

## 🚀 Getting Started

To run this project locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/anasali0011/portfolio-2026.git
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
